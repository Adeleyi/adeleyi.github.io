# adeleyi.github.io

Personal website for **Esther Adenuga** — Computational Linguist / NLP Researcher.

Live at [adeleyi.github.io](https://adeleyi.github.io).

## About this site

Built with [Jekyll](https://jekyllrb.com/) using the [al-folio](https://github.com/alshedivat/al-folio) theme.

- `_pages/` — About, Research, CV, Resources
- `_news/` — short updates shown on the homepage
- `_bibliography/` — publications (BibTeX)
- `assets/` — images, CSS, JS, PDFs

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Site will be available at `http://localhost:4000`.

## Deploying

Pushes to `master` are picked up by the GitHub Pages build (see `.github/workflows/`).
